# Setup

## iOS app

1. Xcode 16+ required.
2. The app project is generated by XcodeGen from `ios/project.yml` (the spec is
   the source of truth; `ios/NutriQuest.xcodeproj` is a build artifact):

   ```bash
   brew install xcodegen   # once
   cd ios && xcodegen generate
   open NutriQuest.xcodeproj
   ```

   `ios/Package.swift` can also be opened directly to work on the three SPM
   targets (NutriQuest, NutriQuestUI, BattleKit), but the runnable app scheme
   lives in the generated project.
3. Signing: personal team (free Apple ID) works. App expires every 7 days on
   device; re-run to re-sign.
4. Run destination: real iPhone for camera scanning; the simulator works for
   manual entry + UI.
5. Backend URL: compiled default comes from the `BackendBaseURL` Info.plist
   key in `project.yml` (currently the Railway deployment). Override at runtime
   via `AppConfig.backendBaseURL` (UserDefaults) for local dev — point it at
   `http://<your-mac-LAN-ip>:4000`, not `localhost` (localhost on an iPhone is
   the phone itself).
6. No external package dependencies. Fonts: bundle Baloo 2 + Quicksand TTFs
   for full typography; falls back to system rounded without them.

## Backend (TypeScript)

```bash
cd backend
npm install
npm run dev            # localhost:4000
npm test               # vitest suite
npm run build          # tsc -> dist/
```

Node >= 22.5 required (the backend uses stdlib `node:sqlite` — no native deps,
no external database). Player state persists to `backend/data/nutriquest.db`;
set `NUTRIQUEST_DB=memory` for an ephemeral database.

Optional env vars: `PORT` (default 4000), `CORS_ORIGIN` (allow-list origin;
defaults to open for hackathon dev), `NUTRIQUEST_ADMIN_TOKEN` (enables
admin-gated routes; unset disables them — see SECURITY.md).

Deploy: Railway (`backend/railway.json`). Attach a persistent volume and set
`NUTRIQUEST_DB=/data/nutriquest.db` — the Railway filesystem is ephemeral and
the server warns when it detects that case.

## Verify

- iOS build + tests: `ios/scripts/test-ios.sh` — regenerates the project,
  picks any available iPhone simulator, runs `xcodebuild test` on the
  NutriQuest scheme (NutriQuestTests + BattleKitTests). All must pass.
- Backend: `cd backend && npm test` — all vitest suites must pass.
- The package targets are iOS-only; a bare `swift build`/`swift test` on macOS
  is not supported (UIKit). Use the script above.
